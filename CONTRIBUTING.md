# Contributing

Thank you for contributing to AI-Photography-Booking-Platform.

## Development Setup

1. Clone the repository.
2. Set up backend and frontend dependencies.
3. Run tests before opening a pull request.

## Pull Request Guidelines

1. Create focused, small changes.
2. Follow existing code style and naming conventions.
3. Add or update tests for changed behavior.
4. Update documentation when needed.
5. Use clear commit messages and PR descriptions.

## Code Review

- Be respectful and constructive.
- Address review comments promptly.
- Keep discussions technical and solution-oriented.
