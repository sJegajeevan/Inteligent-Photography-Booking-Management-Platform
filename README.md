# Intelligent Photography Booking & Management Platform

An AI-powered platform that connects customers with photographers and supports photography package selection, booking, scheduling, payment, photo delivery, and reviews.

## Team Components

### Member 1

Photographer & Portfolio Management

- Photographer profiles
- Portfolio
- Availability
- Photographer Matching Agent

### Member 2

Package & Service Management

- Photography packages
- Services
- Pricing
- Package Recommendation Agent

### Member 3

Booking & Scheduling Management

- Booking
- Scheduling
- Calendar
- Scheduling Agent

### Member 4

Customer & Review Management

- Customer management
- Payment
- Photo delivery
- Reviews
- Validation & Safety Agent

## Technology Stack

- ASP.NET Core Web API
- PostgreSQL
- React
- Flutter
- Python Agentic AI
- Google Maps API
